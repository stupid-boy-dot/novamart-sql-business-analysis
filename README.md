# NovaMart — SQL Business Analysis

## 📌 Project Overview
This project explores retail business data using SQL and MySQL to identify sales trends, understand customer behavior, and evaluate product performance.

## 🎯 Objectives
- Analyze sales and order patterns.
- Explore customer and product performance.
- Practise SQL-based business analysis.
- Extract useful insights to support business decisions.

## 🛠️ Tools Used
- MySQL
- MySQL Workbench
- SQL

## 📚 SQL Concepts Practiced
- SELECT, WHERE, ORDER BY, DISTINCT
- Aggregate functions: SUM, AVG, MIN, MAX, COUNT
- GROUP BY and HAVING
- INNER JOIN, LEFT JOIN, CROSS JOIN
- CASE statements
- LIKE, IN, BETWEEN, and NULL handling
